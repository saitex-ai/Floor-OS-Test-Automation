# Techpack — Techpack view (`/techpacks/view/{id}`)

- **User Story:** there is no ClickUp story for this page; this doc was written from the live uat screens. Proposed: "As a Techpack user, I want one page per techpack where I can read its header, step through its sections, comment, and get its files, so I don't need the full canvas for everyday review."
- **Test-case set:** not yet created in ClickUp.
- **Automated in:** not yet automated (0 of 32).
- **Page objects:** none yet. The canvas has [`canvas.page.ts`](../../src/pages/techpack/canvas.page.ts) and [`canvas.locators.ts`](../../src/locators/techpack/canvas.locators.ts); this page would need its own.
- **Latest run:** none. Every row below was observed live on uat on 2026-10-23, as alice, during the redesign exploration.

This page arrived with the FloorOS redesign (2026-10-22). Creating a techpack (Classic form) and opening a code from the Dashboard both land here. Lifecycle actions (Approve, new revision, lock), pins and presence are still on the canvas — see [`canvas-review.md`](./canvas-review.md) and [`multi-user-presence.md`](./multi-user-presence.md). The Upload techpack screen is in [`create-techpack-ai-mode.md`](./create-techpack-ai-mode.md) (TC:24-25).

**Test data:** use only QA-AUTO techpacks created by the suite, carrying "QA-AUTO — explore test data (pw-hybrid-framework). Safe to delete." (or the suite's own QA-AUTO marker) in Description/Remark. Never trash, approve or edit a real techpack.

## Notes

- **Routes:** the view is `/techpacks/view/{id}`, where `id` is the techpack's source file id. The canvas is `/techpacks/canvas/{id}` with the same id. `/techpacks/{code}` and `/techpacks/drafts/{draftId}` redirect to the view.
- **Locators:**
  - Scope to `getByRole('main').last()`; there are two nested `main` elements.
  - The stepper button needs `getByRole('button', { name: 'Section', exact: true })`; a loose match also hits Size, Previous section and Next section.
  - The h1 is the Techpack Code for a Classic techpack, but the style number for an AI-Mode one.
- **Not covered yet:**
  - adding a comment from the view itself (clicking a Classic techpack's empty viewer in Comment mode opened nothing; not tried on an AI-Mode techpack)
  - the downloads in the Export Tech Pack dialog, and the PDF Tech Pack section's "Export PDF"
  - the Generate buttons in Artwork and Visualization (they call AI services)
