## Notes for whoever picks this up next

TC:10 (audit trail) is **marked `fail` in ClickUp** already — the audit/history view may not currently show this correctly, or may not exist yet as a checkable UI element. Confirm with the team before automating. TC:6 explicitly depends on TC:5 having run first (the "create this Customer now?" prompt only appears after saving with a not-yet-existing Customer name) — write these as a sequential flow within one test, not independent tests, when automating. Not yet live-probed against the running app — no locators confirmed; likely route is `/crm/contacts/new` based on the parallel confirmed for Create Customer (`/crm/customers/new`).
