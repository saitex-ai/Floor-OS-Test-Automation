# BOM — Bill of Materials List

- **User Story:** As a BOM user, I want to see every BOM in one sortable, filterable list — by status, techpack code, customer or season — so I can find and open the record I need.
- **Test-case set:** not yet created in ClickUp.
- **Automated in:** [`tests/regression/bom/01-bom-list.spec.ts`](../../tests/regression/bom/01-bom-list.spec.ts) — 17 cases, all real `test()` blocks.
- **Page objects:** [`bom-list.page.ts`](../../src/pages/bom/bom-list.page.ts) + [`bom-list.locators.ts`](../../src/locators/bom/bom-list.locators.ts) (fixture `bomListPage`)
- **Latest run:** uat, 2026-10-08, as `alice` — **17/17 pass**.

The list lives at `/bom`. It shares the Techpacks list's grid framework (same toolbar). Read-only: these cases never change a BOM, so they run against whatever BOMs the environment has.

**Test data:** every techpack and BOM this suite creates carries "QA-AUTO — BOM regression test data (pw-hybrid-framework). Safe to delete." in its Description (shown as **Remark** in the techpack and BOM lists), so it can be found and deleted from the backend later. See `tests/regression/bom/support/disposable-bom.ts`.

## Notes

- BOM has only **All / Open / Approved** tabs (no Draft, no Cancelled — a Cancelled BOM is only findable through the Status column filter, and the UI has no Cancel action at all).
- The tab badges load separately from the grid rows; `BomListPage.waitForTabCounts()` waits for them before any count is read.
