# BOM — Permissions

- **User Story:** As a BOM admin, I want BOM lifecycle actions limited to the roles allowed to take them, so a non-approver can read a BOM but not approve, reopen or revise it.
- **Test-case set:** not yet created in ClickUp.
- **Automated in:** [`tests/regression/bom/05-bom-permissions.spec.ts`](../../tests/regression/bom/05-bom-permissions.spec.ts) — TC:1–TC:4 (all real `test()` blocks). TC:5–TC:12 are new and not yet automated.
- **Page objects:** [`bom-detail.page.ts`](../../src/pages/bom/bom-detail.page.ts) / [`bom-items.page.ts`](../../src/pages/bom/bom-items.page.ts) + their locators (fixtures `bomDetailPage`, `bomItemsPage`)
- **Latest run:** 2026-10-30, as `alice` (and `bob` as the second user), on main cb65c1e plus this change, after that day's dev and uat deploy, each with 1 and with 2 workers: uat **4/4 pass**, dev **4/4 pass** (`bob` is the second user on dev too; TC:4's setup now gives its lines a supplier, which dev's Costing Approve requires: before that it answered 409 `LIFECYCLE_BLOCKED`, `missingVendor`). One uat 2-worker run failed in setup when Create BOM answered 500 twice (first try and retry); the rerun passed. Per-TC results are in the Verified columns. On 2026-10-28 (main 2b1b11a) the results were the same, but two other uat 2-worker runs that day failed in this file's setup on uat server-side errors: Create BOM answered 500 INTERNAL_ERROR once (the setup now retries a 5xx once), and the "Add Inventory Item" search timed out once. Before that: uat, 2026-10-22 (main `5f975af`, after the redesign) — **skipped**: no second-user credentials were set for uat then. Before that: uat 2026-10-08, 4/4.
- **Second user:** `BOM_SECOND_USER_UAT` / `BOM_SECOND_PASSWORD_UAT` = `bob` (Qc-lead) are now set in `.env` (the user said yes on 2026-10-23).

Alice (admin) builds one disposable BOM and drives it Open → Approved; the second user (`BOM_SECOND_USER_<ENV>`, a Qc-lead such as `bob`, in its own isolated browser context) looks at the same BOM in each state. Each case compares bob's control against Alice's on the same screen. Skips when no second user is configured.

**Test data:** every techpack and BOM this suite creates carries "QA-AUTO — BOM regression test data (pw-hybrid-framework). Safe to delete." in its Description (shown as **Remark** in the techpack and BOM lists), so it can be found and deleted from the backend later. See `tests/regression/bom/support/disposable-bom.ts`.
